# Optimizer mechanics fixture

See [the optimizer guide](../../docs/phase-optimizer.md). The public verifier key
is an RFC 8032 test-vector key: replace it before registering any real study.
No private keys, real provider credentials, or successful benchmark observations
are included. Input file hashes are fixed in `config.json`.

This fixture exercises configuration and local task planning. The two-task
holdout intentionally cannot establish a statistically supported improvement.
For HTTP execution, add your reviewed TRC operation plan to an intervention and
use the existing parameter-bound approval route described in the guide.
