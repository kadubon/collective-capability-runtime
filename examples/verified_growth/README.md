# Offline verified growth fixture

Run `ccr optimizer growth-example --json` with the optimizer extra installed.
The command supplies ephemeral signing keys and a temporary synthetic store,
executes the workcell/task/evidence/reuse path and compares frozen arms. It
does not contact model providers or establish empirical acceleration.

`profile.json` is an inert registration template. Its public key has no shipped
private counterpart. It declares formation, transfer, two receiver services
and an immediate baseline. `packet.json` is a software mechanics fixture.
All companion fixtures under `interchange/` are evidence examples only.

See the packaged [growth guide](../../docs/verified-growth.md) for exact
contracts, resource accounting, lifecycle, search limits and migration.
