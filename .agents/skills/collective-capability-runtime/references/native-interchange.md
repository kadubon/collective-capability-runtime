# Native interchange development boundary

Read `docs/native-interchange.md` and its development evidence record. The path
is opt-in synthetic training and remains under release qualification. Use
`optimizer native sources/inspect` for local inspection, and the isolated
`optimizer native example` only with the pinned optional dependencies installed.

Register immutable existing-action bindings before work. Projection/checking is
read-only; stage and explicit admit are separate transactional writes with
revision control. Only the existing CCR plan/reservation/task/lease/result path
executes work. After signed observations, CPCF replanning produces another
proposal requiring separate admission. Do not flatten its conditional policy.

CAIT totals reconcile original sources; they never add the same reward or stock
again. Native source authentication remains unestablished, separately from CCR
verification of original signatures. A negative VEK check can complete work
without creating capability service. Pending, timeout, invalid, inconclusive
and censored work remain distinct. Neither censoring nor unknown execution
releases reservations or authorizes retry.

Do not claim Phase 1 OAWM completion, external acceleration, a transferred CPCF
continuation guarantee, causal attribution, production validation, or 1.9.0
publication from these development tests.
